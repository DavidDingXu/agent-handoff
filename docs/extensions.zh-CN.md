# 扩展与定制

[English](extensions.md) | 简体中文

agent-handoff 不把“可扩展”等同于“所有东西都加载插件”。配置能解决的问题优先使用声明式配置；只有实现差异足够大、配置无法表达时，才考虑版本化插件 interface。这样社区可以定制，又不会牺牲跨平台和数据安全。

## 当前扩展点

| 扩展点 | 方式 | 是否改核心 | 适合场景 |
| --- | --- | --- | --- |
| 文件服务 Provider | `config.json` | 否 | 国内文件服务、对象存储、企业上传 API |
| Resolver 页面 | HTTPS 静态页配置 | 否 | 替换默认链接展示页；CLI 导入不依赖它 |
| 新增智能体 | Go 适配器 | 是 | OpenCode、DeepSeek Harness 等新的原生会话格式 |
| 密钥扫描规则 | Go 规则 + 测试 | 是 | 新的高置信凭据格式 |
| 捆绑包字段 | 版本化 schema | 是 | 新的跨智能体可移植元数据 |

### 文件服务 Provider

这是普通用户最实用的扩展点，不需要安装或执行第三方插件。配置描述上传 URL、multipart/raw、header、表单字段，以及如何从 JSON/文本响应提取下载 URL。核心负责加密、HTTP 请求、URL 校验、失败隔离和 zip 回退。

社区可以贡献 provider 配置示例。示例必须说明：

- 服务是否要求账号和 token；
- 文件大小、保留时间、下载次数和地域限制；
- token 使用 `${ENV_NAME}` 引用，不能直接写入配置；
- 下载 URL 是否允许接收方直接 `GET`；
- 至少一次真实密文上传/下载校验结果。

详见 [自定义 Provider](link-service.zh-CN.md#自定义-provider)。

### 新增智能体适配器

智能体适配器直接读写 Codex、Claude Code 或未来工具的原生状态，承担任务发现、原生恢复、追加写入、备份、身份重写和 verify。当前通过源码适配器贡献，完整流程见 [新增其他智能体](adding-agent.zh-CN.md)。

它是未来唯一值得评估为“运行时插件”的能力，因为不同 Agent 的实现差异确实很大。首个计划适配的是 [OpenCode](https://github.com/anomalyco/opencode)；[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 会在开发者预览期的会话和存储 API 足够稳定、可以安全原生恢复后接入。现在只有 Codex 和 Claude 两个实现，还不足以证明稳定公共 interface。第三个真实适配器加入后再评估：

- 必须覆盖 macOS、Linux、Windows，不能使用不支持 Windows 的 Go `plugin` 包；
- 若采用进程外协议，必须版本化并明确读写权限、备份和失败原子性；
- 插件不能绕过 preview、显式确认、重复检测或只追加写入合同；
- 每新增一个 Agent，CI 必须扩展到 N x N 交接矩阵。

在这些条件被真实实现验证前，显式 Go 路由比过早 registry 更容易审计。

### 密钥扫描规则

扫描规则更适合声明式配置，而不是可执行插件。后续可以开放“组织自定义正则 + 脱敏模板”，但规则必须在任何网络上传之前由核心执行，provider 无权关闭。内置规则仍只接受高置信模式并补误报测试。

### 捆绑包扩展

v2 捆绑包允许增加向后兼容字段和智能体专用目录。新增字段先建 Issue，写清来源、消费者、缺失时行为和旧版本读取策略。路径清理、大小限制、checksum、格式版本和不可信内容处理始终由核心负责，不开放第三方任意改写 zip。

## 不做成插件的核心合同

- AES-256-GCM 加密、URL fragment 密钥和 checksum 校验；
- 导出前密钥扫描与用户显式确认；
- `preview` 后再确认导入；
- 原生任务只追加写入、写前备份和重复导入 ledger；
- bundle 路径、大小、schema 与来源智能体校验；
- Codex/Claude 原生提问工具映射。

这些能力一旦可被第三方替换，定制就可能变成密钥泄露、数据破坏或无法恢复的任务状态。

## 贡献流程

新增扩展点先建 Issue，写清使用者、信任模型、失败回退和跨平台验收标准。从最新 `main` 创建短期 `feat/*` 分支，经测试和 PR 合并。配置或协议的不兼容变更必须升级版本，并保留旧版本读取路径。
